# 🌱 OpenImpact

> **What if every act of kindness could create another one?**

OpenImpact is an open-source generosity platform focused on **transparency, measurable impact, and the ripple effect of giving**.

## ✨ Features

* 💰 **Impact Calculator** — See what a contribution can achieve through interactive charts.
* 🤖 **AI Field Storyteller** — Turn raw field notes into authentic impact stories with Google Gemini.
* 🌊 **Generosity Ripple** — Visualize how one act of generosity inspires another.
* 🔎 **Open Audit** — Explore itemized budgets and download the public CSV ledger.

## 🛠️ Tech Stack

* React
* Recharts
* Google Gemini
* JavaScript
* CSS
